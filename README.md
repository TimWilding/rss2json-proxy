# rss2json-proxy
This is a proxy for converting rss feeds to json similar to https://github.com/dan-mba/rss2json-proxy. It is designed to build a Vercel serverless app that can be run with the H3K website at https://homesheatandhealthykids.github.io.
The app can be updated by pushing to the github repo.

* Testing the code can be done locally in a Docker container
